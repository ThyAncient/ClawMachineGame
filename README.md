## About the Game

**ClawMachineGame** is a cozy claw machine game commissioned by my girlfriend. The goal is simple: operate the claw machine and collect adorable little Kelvin plushies, each with their own spawning rates.

This project is a personal gift, so a public release is not planned.

## Features

- **Collectible Plushies** — Collect little Kelvin plushies from the claw machine.
- **Unique Spawn Rates** — Different plushies have different chances of appearing, making some more difficult to collect than others.
- **Claw Machine Gameplay** — Experience the fun of operating a claw machine and collecting its prizes.
